Both models take raw latitude, longitude and week (1–48) and return a per-species occurrence probability (sigmoid). The grid covers 25° W – 45° E, 34° N – 72° N at the chosen step; every cell is one model call per model, run on this device with ONNX Runtime Web. Species are matched between the two label files by their species code (11,880 shared; 132 only in V3.0.0, 2,202 only in V3.0.4), with the scientific name as the fallback.
